# SHAKTI-HW-01: Hardware Approval Assurance

Production hardware must be held until exact-model approval applicability, authoritative evidence, calibration, security, and end-to-end test requirements are documented. The user's RupayKg rule is to use only hardware with verified applicable MeitY approval. Do not assume one certificate applies to all instrument categories. If evidence is missing, status is HOLD.
