# Live Auction Source Evidence

This directory contains machine-generated discovery snapshots.

Rules:

- Discovery is not verification.
- A discovered record is not decision evidence.
- Production certification remains OFF until source-specific evidence gates pass.
- Exact auction/lot identity, current process documents, corrigenda, title/possession and bidder obligations remain mandatory where applicable.
- Do not bypass authentication, CAPTCHA, robots controls, paywalls or undocumented APIs.
- BAANKNET may require an authorised export, documented API or controlled user evidence intake if its public surface does not expose machine-readable search results.
